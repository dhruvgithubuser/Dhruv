# Character-motion pack (optional upgrade)

The rendered video already moves: every realistic shot has 3D camera motion, with near objects moving faster than far ones. **People inside the shots don't move**, because that needs a GPU video model, which this server doesn't have.

To get real character motion like the reference video, generate these **10 key shots** in **Hailuo AI** or **Kling AI** (both give free daily credits). Then send me the clips and I'll swap them into the video.

**How to do it**
1. Open hailuoai.video (or klingai.com) and choose **Image to Video**.
2. Upload the image (`public/assets/stills/<name>.png`; I'll send them).
3. Paste the motion prompt. Set **5 seconds**, 16:9, and turn off any added audio.
4. Download each clip and name it like the image (e.g. `c03_reno.mp4`).
5. Send the clips to me. I'll replace those shots and re-render. Nothing else changes.
