# GTA V Farewell × GTA VI Welcome — 60 s reel kit

1. Follow `PROMPTS.md` to make the 10 scene clips (keyframe still → image-to-video).
2. Save them in `clips/` as `01.mp4 … 10.mp4` (scenes 05 and 06 can be `05a/05b`, `06a/06b`, 3 s each).
3. Optional: `audio/music.mp3` (score) and `audio/vo.wav` (your recorded lines, one 60 s track).
4. Run `./assemble.sh` (needs ffmpeg) → `out/gta_farewell_reel.mp4`, 1080×1920, 24 fps, titles + fade to black.

Clips, audio and reference photos are git-ignored so your photos never get committed.
